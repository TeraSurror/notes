
Data Validation:
1. Ensure data meets quality standards before it reaches a foundation model
2. Standardize formats
3. Values are within correct ranges
4. Required fields present
5. Freshness, accuracy, data integrity, corruption


Preprocessing:
1. Transforms raw source data to structured data

Data enrichment:
1. Enrich with additional context to get a better response
2. Entity extraction
3. Metadata tagging
4. Sentiment analysis

Multimodal processing:
1. Text, image, audio and tabular data
2. Processing through specialized sub pipelines 
3. Combining outputs for FM consumption
